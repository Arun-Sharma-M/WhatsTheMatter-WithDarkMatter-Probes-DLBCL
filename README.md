# WhatsTheMatter-WithDarkMatter-Probes-DLBCL

## Overview

This repository contains analysis scripts for the transcriptomic
investigation of diffuse large B-cell lymphoma (DLBCL), with a focus on
long non-coding RNAs (lncRNAs), protein-coding mRNAs, and potential
relationships between their expression patterns.

The workflow covers RNA-sequencing read processing, read-count
generation, differential-expression analysis, expression and
candidate-gene visualisation, survival analysis, computational
prediction of lncRNA--mRNA interactions, and correlation analyses that
assess cohort and stromal-score effects.

The repository includes scripts used at different stages of the
analysis. Some scripts require intermediate files generated by earlier
steps, and some contain paths or assumptions specific to the original
computing environment. Review the **Inputs and reproducibility notes**
before running them.

## Analysis overview

### 1. RNA-seq processing and read counting

The documented sequencing workflow uses:

-   SRA Toolkit (`fastq-dump`) to retrieve FASTQ files.
-   FastQC to assess read quality.
-   HISAT2 to align paired-end reads to the hg38 reference genome.
-   SAMtools to convert, sort, index, and assess BAM files.
-   BEDTools `multiBamCov` to generate read counts over the supplied
    lncRNA and mRNA BED annotations.

The SRA and TCGA data were not processed identically at the raw-read
stage: the documented TCGA workflow starts from BAM files downloaded
from the Genomic Data Commons, so FASTQ retrieval and HISAT2 alignment
are not repeated for those samples. The RNA-seq pipeline file lists the
commands and reference files used.

Corresponding file: 1.RNA_Seq_pipeline.txt

### 2. Differential expression and expression processing

The DESeq2 and expression-workflow scripts use read-count matrices and
sample metadata to perform differential-expression analysis and generate
downstream expression tables. The workflow also includes conversion of
read counts to TPM and filtering/selection of candidate transcripts.

Check that the count matrix, sample metadata, sample order, transcript
identifiers, and annotation files agree before running these scripts.
Differential-expression models and filtering thresholds should be
interpreted according to the actual settings in the corresponding script
and analysis.

Corresponding files:
* 2.DESeq2_DLBCL_SRA_TCGA_merge_lncRNA.r
* 3.SRA_TCGA_lncRNA_DLBCL2_Workflow.R

### 3. Candidate-set overlap and expression plots

The Venn-diagram script compares selected lncRNA and mRNA sets from
differential-expression outputs. The SlimRNA plotting script loads
expression tables and metadata to visualise selected genes. These
scripts depend on intermediate CSV files and gene lists produced or
supplied elsewhere in the workflow.

Corresponding files:
* 4.Venndiagram_upr.r
* 5.TCGA_DLBCL2_SlimRNA_boxplot.r

### 4. Survival analysis

`6.KM_survival_DLBCL.R` uses TCGA DLBCL clinical metadata and expression
data for survival analysis. The expected clinical input in the script is
`TCGA_DLBCL_meta.csv`; the expression input referenced in the script is
`DESEQ2_TPM_DLBCL2_lncRNA_mRNA.csv`.

Survival analyses depend on the availability and quality of follow-up
time, vital status, and expression measurements. Verify the
clinical-field names, missing-value encodings, and expression-group
definitions before interpreting results.

### 5. IntaRNA interaction prediction

`7.IntaRNA_usage_DLBCL.txt` contains commands for the three selected
lncRNA--mRNA pairs:

-   `lnc-SPARC-2:3` and `SPARC`
-   `lnc-ADAMTS1-2:1` and `ADAMTS1`
-   `lnc-FXYD2-1:5` and `FXYD2`

The commands specify a minimum seed base-pairing requirement of 4 and
request target, query, and pairwise output files. The FASTA files named
in the commands must be present in the working directory. Confirm the
command-line options supported by your installed IntaRNA version before
execution. Predicted interactions are computational hypotheses and do
not by themselves establish biological regulation.

### 6. Correlation and cohort-adjusted analyses

The correlation scripts analyse selected lncRNA--mRNA combinations. The
candidate set in `8.Cohort_Stromal_Adjusted_Associations.R` contains
three lncRNAs and nine mRNAs, giving 27 combinations:

**lncRNAs** - `lnc-ADAMTS1-2:1` - `lnc-FXYD2-1:5` - `lnc-SPARC-2:3`

**mRNAs** - `ADAMTS1` - `ADAMTS5` - `ATOX1` - `BCL6` - `FXYD2` -
`FXYD6` - `FXYD6-FXYD2` - `INO80` - `SPARC`

The cohort/stromal-adjusted script calculates SRA- and TCGA-specific
Spearman correlations, fits rank-based regression models adjusted for
cohort and stromal score, tests cohort-by-expression interactions,
integrates results, and creates faceted plots.
`8.Spearmann_Correlation_NvsT.R` contains additional groupwise and
permutation-based analyses, including differential-correlation tests and
BH multiple-testing correction.

A statistically significant correlation is an association, not proof of
direct molecular interaction or causal regulation. The SRA tumour group
is smaller than the TCGA tumour group in the sample layout specified by
the scripts; consider this difference when interpreting precision and
cross-cohort comparisons.

## Input files and directory setup

The scripts refer to intermediate files by filename, and several scripts
contain absolute paths from the original computer. Place the required
input files in the expected working directory or update the paths before
running a script.

Input filenames referenced by one or more scripts include:

-   `SRA_TCGA_DLBCL_for_PCA_meta.csv` --- sample metadata.
-   `fordeseq_SRA_TCGA_merge_hisat2_N_T_DLBCL_lncRNA_RC.tsv` --- lncRNA
    read-count matrix.
-   `fordeseq_SRA_TCGA_merge_hisat2_N_T_DLBCL_mRNA_RC.tsv` --- mRNA
    read-count matrix.
-   `TPM_DLBCL2_lncRNA_mRNA_boxplot.csv` --- combined
    candidate-transcript TPM matrix used by correlation analysis.
-   `DLBCL_stromal_scores_Results.csv` --- stromal-score data used in
    adjusted correlation analysis.
-   `TCGA_DLBCL_meta.csv` --- clinical metadata for survival analysis.
-   `DESEQ2_TPM_DLBCL2_lncRNA_mRNA.csv` --- expression input referenced
    by the survival script.
-   `String_exp_list.csv` --- gene list referenced by the SlimRNA
    plotting script.
-   `lncipedia_5_2_hg38.bed` --- lncRNA genomic intervals.
-   `hg38_NCBIRefseq.bed` --- mRNA genomic intervals.
-   `mRNA_read_length.tsv` --- gene-coordinate/length data used by the
    mRNA expression workflow.

These are examples of inputs referenced in the scripts, not a guarantee
that all files are included in this repository. Confirm that each file
is available before running its dependent script.

## Suggested execution order

The order depends on which intermediate data are already available. A
typical sequence is:

1.  Run or review `1.RNA_Seq_pipeline.txt` to obtain read-count
    matrices.
2.  Run `3.SRA_TCGA_lncRNA_DLBCL2_Workflow.R` to process expression data
    and create intermediate tables.
3.  Run `2.DESeq2_DLBCL_SRA_TCGA_merge_lncRNA.r` for lncRNA
    differential-expression analysis.
4.  Run `4.Venndiagram_upr.r` to compare selected candidate sets.
5.  Run `5.TCGA_DLBCL2_SlimRNA_boxplot.r` to plot selected expression
    sets.
6.  Run `6.KM_survival_DLBCL.R` for survival analysis, after checking
    clinical and expression inputs.
7.  Run `7.IntaRNA_usage_DLBCL.txt` commands for the selected
    lncRNA--mRNA pairs.
8.  Run `8.Cohort_Stromal_Adjusted_Associations.R` and/or
    `8.Spearmann_Correlation_NvsT.R` for correlation analyses.

This is a suggested navigation order, not a fully automated pipeline.
Some scripts use outputs generated elsewhere, and paths or filenames may
need to be updated to match your local setup.

## Reproducibility and interpretation notes

-   Use compatible genome assemblies and annotation coordinates for the
    alignment and read-counting steps.
-   Preserve sample identifiers consistently between expression matrices
    and metadata.
-   Check that all intended samples are represented in the count
    matrices before differential-expression or correlation analysis.
-   Inspect FastQC and alignment statistics before downstream analysis.
-   Review duplicate transcript/gene identifiers and missing values
    before statistical testing.
-   Multiple-testing correction is important when evaluating the 27
    candidate pairs or larger sets of associations; use the reported FDR
    values rather than relying only on nominal p-values.
-   Cohort-adjusted and stromal-adjusted associations remain
    observational and may be affected by sample size, tissue
    composition, measurement differences, and other unmeasured
    confounders.
-   Update hard-coded file paths, confirm required packages and software
    versions, and validate the exact input columns before running each
    script.
-   Do not treat predicted IntaRNA interactions or expression
    correlations as experimental validation.
